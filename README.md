## 新加坡机房的延迟和线路：三网 GIA 是真优势，但赢不了物理距离

SG_8 的核心卖点在回程：三网都走 59.43 段（AS4809）的 CN2 GIA 骨干，去程从新加坡本地出口、经 CTGNet 接入电信 CN2 骨干。对联通、移动用户来说，这意味着晚高峰的稳定性和丢包表现向电信看齐，这一点是香港、东京、大阪的 CN2 GIA 套餐给不了的。

延迟则是另一回事。新加坡在大陆南边更远处，到国内的延迟天然比香港高。老 SG_1 的第三方实测可以作参考：到杭州电信约 68ms、苏州电信约 80ms、北京移动约 81ms、北京联通约 121ms；同时期香港机房的延迟普遍在 10–30ms。SG_8 线路规格相同、物理距离没变，量级大体可以参照，具体还是建议下单后自己测。

去程方面，第三方路由测试显示电信路径较顺，移动经 CMI 转 NTT，联通去程要走 4837 绕日本 NTT，表现波动比较大——有一次三网测速里，北京联通下行只跑出个位数 Mbps，同一轮测试里电信和移动的下行都能到 2.5Gbps 上下。电信、移动用户基本可以放心，联通用户建议先买一个月实测，再决定长期方案。
